Method

Non-overlapping query anchors; bounded greedy chaining (32 recent chains), maximum step 10,000 bp or k if larger; local drift 500 bp. Placement requires at least 3 anchors, 500 covered bases (or 3k if larger), 50% query coverage, 90% dominant-chain support, and no substantial secondary chain. These are heuristic thresholds, not calibrated confidence. Circular mode labels possible origin crossings; it does not rotate or force placement of crossing contigs.
